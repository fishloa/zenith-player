Zenith icon pack

Files:
- zenith-icon-source.svg           Source vector
- zenith-icon-1024.png             Master 1024x1024 PNG
- Zenith_iOS_AppIcon.appiconset/   iOS-ready asset catalog set
- Zenith_tvOS_master/              Flat master for tvOS/Icon Composer workflow

Renderer used: cairosvg

Notes:
- The PNGs are opaque and suitable for app icon workflows.
- The iOS appiconset includes common iPhone/iPad plus App Store marketing icon files.
- For tvOS, Apple supports layered image-stack workflows in Xcode; this pack includes the flat master only.
