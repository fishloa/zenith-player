Zenith tvOS master

Apple's current guidance indicates:
- tvOS app icons can be generated from a single 1024×1024 image in Xcode asset workflows.
- tvOS icons are also designed as layered image stacks in Xcode for focus/parallax treatments.

This folder contains the approved flat master for deriving tvOS assets in Xcode or Icon Composer.
If you want, the next step is a dedicated layered tvOS icon pack rather than this flat master.
